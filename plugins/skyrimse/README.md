# The Elder Scrolls V: Skyrim Special Edition

Official Loom game plugin (`github.com/enrell/loom/plugins/skyrimse`).

- **Detection:** Steam 489830, GOG 1711230643, registry
- **Mods go to:** `Data` (data layout)
- **Load order:** Plugin load order: `%LOCALAPPDATA%/Skyrim Special Edition/Plugins.txt`, light plugins (`.esl`).
- **Tools:** xTranslator, SSE Auto Translator, SSEEdit, BodySlide, Nemesis Unlimited Behavior Engine
- **Nexus Mods:** `nexusmods.com/skyrimspecialedition`

Executables:

- `SkyrimSE.exe` — Skyrim Special Edition (default)
- `skse64_loader.exe` — SKSE (optional)
- `SkyrimSELauncher.exe` — Skyrim Launcher (optional)

## Tested

Detection (GOG registry), plugin headers, implicit masters and Creation Club handling verified against Skyrim Anniversary Edition (GOG, 1.6.1179).
