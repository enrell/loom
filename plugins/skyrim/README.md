# The Elder Scrolls V: Skyrim

Official Loom game plugin (`github.com/enrell/loom/plugins/skyrim`).

- **Detection:** Steam 72850, registry
- **Mods go to:** `Data` (data layout)
- **Load order:** Plugin load order: `%LOCALAPPDATA%/Skyrim/Plugins.txt`, ordered by file times.
- **Tools:** TES5Edit
- **Nexus Mods:** `nexusmods.com/skyrim`

Executables:

- `TESV.exe` — Skyrim (default)
- `skse_loader.exe` — SKSE (optional)

## Tested

Not yet verified on a real install. If you own the game, please run `loom game add skyrim` and `loom doctor skyrim` and report the result.
