# Fallout 3

Official Loom game plugin (`github.com/enrell/loom/plugins/fallout3`).

- **Detection:** Steam 22300, 22370, registry
- **Mods go to:** `Data` (data layout)
- **Load order:** Plugin load order: `%LOCALAPPDATA%/Fallout3/plugins.txt`, ordered by file times.
- **Tools:** FO3Edit
- **Nexus Mods:** `nexusmods.com/fallout3`

Executables:

- `Fallout3.exe` — Fallout 3 (default)
- `fose_loader.exe` — FOSE (optional)

## Tested

Not yet verified on a real install. If you own the game, please run `loom game add fallout3` and `loom doctor fallout3` and report the result.
