# The Witcher 3: Wild Hunt

Official Loom game plugin (`github.com/enrell/loom/plugins/witcher3`).

- **Detection:** Steam 292030, folder names
- **Mods go to:** `Mods` (package layout)
- **Load order:** No plugin load order.
- **Tools:** Script Merger
- **Nexus Mods:** `nexusmods.com/witcher3`

Executables:

- `bin/x64/witcher3.exe` — The Witcher 3 (default)
- `bin/x64_dx12/witcher3.exe` — The Witcher 3 (DirectX 12) (optional)

## Tested

Not yet verified on a real install. If you own the game, please run `loom game add witcher3` and `loom doctor witcher3` and report the result.
