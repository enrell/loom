# The Elder Scrolls IV: Oblivion

Official Loom game plugin (`github.com/enrell/loom/plugins/oblivion`).

- **Detection:** Steam 22330, registry
- **Mods go to:** `Data` (data layout)
- **Load order:** Plugin load order: `%LOCALAPPDATA%/Oblivion/Plugins.txt`, ordered by file times.
- **Tools:** TES4Edit
- **Nexus Mods:** `nexusmods.com/oblivion`

Executables:

- `Oblivion.exe` — Oblivion (default)
- `obse_loader.exe` — OBSE (optional)

## Tested

Not yet verified on a real install. If you own the game, please run `loom game add oblivion` and `loom doctor oblivion` and report the result.
