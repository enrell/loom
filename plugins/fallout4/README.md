# Fallout 4

Official Loom game plugin (`github.com/enrell/loom/plugins/fallout4`).

- **Detection:** Steam 377160, registry
- **Mods go to:** `Data` (data layout)
- **Load order:** Plugin load order: `%LOCALAPPDATA%/Fallout4/Plugins.txt`, light plugins (`.esl`).
- **Tools:** xTranslator, FO4Edit, BodySlide
- **Nexus Mods:** `nexusmods.com/fallout4`

Executables:

- `Fallout4.exe` — Fallout 4 (default)
- `f4se_loader.exe` — F4SE (optional)
- `Fallout4Launcher.exe` — Fallout 4 Launcher (optional)

## Tested

Not yet verified on a real install. If you own the game, please run `loom game add fallout4` and `loom doctor fallout4` and report the result.
