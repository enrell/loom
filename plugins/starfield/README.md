# Starfield

Official Loom game plugin (`github.com/enrell/loom/plugins/starfield`).

- **Detection:** Steam 1716740, registry
- **Mods go to:** `Data` (data layout)
- **Load order:** Plugin load order: `%LOCALAPPDATA%/Starfield/Plugins.txt`, light plugins (`.esl`).
- **Tools:** xTranslator, SF1Edit
- **Nexus Mods:** `nexusmods.com/starfield`

Executables:

- `Starfield.exe` — Starfield (default)
- `sfse_loader.exe` — SFSE (optional)

## Tested

Not yet verified on a real install. If you own the game, please run `loom game add starfield` and `loom doctor starfield` and report the result.
