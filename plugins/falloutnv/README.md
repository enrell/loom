# Fallout: New Vegas

Official Loom game plugin (`github.com/enrell/loom/plugins/falloutnv`).

- **Detection:** Steam 22380, registry
- **Mods go to:** `Data` (data layout)
- **Load order:** Plugin load order: `%LOCALAPPDATA%/FalloutNV/plugins.txt`, ordered by file times.
- **Tools:** FNVEdit
- **Nexus Mods:** `nexusmods.com/newvegas`

Executables:

- `FalloutNV.exe` — Fallout: New Vegas (default)
- `nvse_loader.exe` — NVSE (optional)

## Tested

Not yet verified on a real install. If you own the game, please run `loom game add falloutnv` and `loom doctor falloutnv` and report the result.
